# CivicGuide AI 🗳️🤖

**CivicGuide AI** is a state-of-the-art, interactive platform designed to empower citizens with the knowledge and tools needed for effective democratic participation. Built with a focus on transparency, accessibility, and AI-driven insights, it simplifies the complexities of the voting process.

---

## 🌟 Key Features

### 1. AI-Powered Candidate Explorer
- **Real-Time Pulse:** Track candidate statements, upcoming rallies, and popularity metrics.
- **AI Side-by-Side Comparison:** Select any two candidates and use **Google Gemini AI** to generate a factual, professional comparison of their platforms and focus areas.
- **Regional Filtering:** Automatically filters candidates based on your location/constituency.

### 2. AI Civic Assistant & Fact-Checker
- **Interactive Chat:** Ask questions about voting procedures, registration, or eligibility.
- **News Fact-Checking:** Paste news snippets to receive a "Trust Score" and analytical summary generated by Gemini AI, helping you navigate misinformation.

### 3. Personalized Election Timeline
- **Regional Updates:** Dynamic timeline that updates based on your city and state.
- **Notification Reminders:** Set reminders for critical dates like registration deadlines and polling days.
- **Visual Status:** Track completed vs. upcoming election milestones.

### 4. Mock Voting Simulator
- **Digital Practice:** A high-fidelity, risk-free simulation of the Electronic Ballot process.
- **Step-by-Step Guidance:** Learn the verification path from ID check to casting your vote and receiving a simulated receipt token.

### 5. Multilingual Accessibility
- Full support for major Indian languages: **English, Hindi, Bengali, Telugu, Marathi, and Tamil**.
- Unified experience with instant translation across all pages.

### 6. Civic IQ Quiz
- Test your knowledge of the democratic process with an interactive quiz.
- Receive instant feedback and detailed explanations for each answer.

## 🛠️ Tech Stack

- **Frontend:** React 18+ with TypeScript
- **Build Tool:** Vite
- **Styling:** Tailwind CSS (Modern Light Aesthetic)
- **Animations:** Framer Motion
- **AI Core:** Google Gemini AI (@google/genai SDK)
- **Database/Auth:** Firebase (Firestore & Firebase Auth)
- **Icons:** Lucide React

## 🚀 Getting Started

### 1. Environment Setup
Create a `.env` file in the root directory and add your API keys:
```env
GEMINI_API_KEY=your_gemini_api_key_here
```

### 2. Installation
```bash
npm install
```

### 3. Development
```bash
npm run dev
```

### 4. Build for Production
```bash
npm run build
```

## 📂 Project Structure

- `src/pages/`: Core views (Dashboard, Timeline, Simulator, Chatbot, Quiz).
- `src/components/`: Reusable UI elements, including the AI Comparison Modal and Skeletons.
- `src/lib/`: Utility functions and helper classes.
- `src/translations/`: Multi-language dictionary logic.
- `firebase.ts`: Firebase initialization and firestore rules management.

## 🛡️ Privacy & Safety
CivicGuide AI prioritizes user privacy. All AI analyses are based on publicly available data, and the Voting Simulator is exclusively for educational purposes—no real votes are cast or recorded.
